# Physics-informed ML prediction of corrosion-fatigue crack growth in AA3003 FSW joints

Code and consolidated dataset for the manuscript

> Physics-informed machine learning prediction of fatigue crack growth
> in pre-corroded AA3003 friction stir welded joints: coupled
> temperature and inhibitor effects
> (submitted to the *International Journal of Fatigue*, 2026)

A condition-wise Paris law forms the physics baseline, an Arrhenius
model links the temperature dependence of crack growth to the
corrosion activation energy measured independently by gravimetry, and
a Gaussian process learns only the residual. Trained at 25 and
85 degC only, the hybrid model predicts the unseen 55 degC curves
(0.20 decades error, R2 = 0.93), and the framework then predicts
residual life at the untested 45 and 65 degC with uncertainty bands.

## Data provenance

No new experiments were performed. All experimental data originate
from the authors' two previously published papers, which remain the
primary reference for the experiments:

- I. Chekalil et al., *Effect of corrosion environments on the
  mechanical properties of friction stir welded aluminum alloy
  AA3003*, J. Mater. Res. Technol. 33 (2024) 2353-2364.
  [10.1016/j.jmrt.2024.09.167](https://doi.org/10.1016/j.jmrt.2024.09.167)
- I. Chekalil et al., *Corrosion behavior of AA3003 friction stir
  welded joints*, Colloids Surf. A 680 (2024) 132673.
  [10.1016/j.colsurfa.2023.132673](https://doi.org/10.1016/j.colsurfa.2023.132673)

## Requirements

Base MATLAB only (developed and tested on R2026a). No toolboxes are
needed; the regression, gradient-boosted-tree and Gaussian-process
models are implemented natively in the stage scripts.

## How to run

```matlab
cd matlab
run_all
```

This regenerates every result figure into `figures/` and every derived
table into `data/derived/`. Total runtime is a few minutes; stage 4
(cross-validation and bootstrap) takes most of it.

## Repository structure

| Path | Content |
|---|---|
| `matlab/s1_paris_baseline.m` | Paris refits with bootstrap CIs (Fig. 2, Table 4) |
| `matlab/s2_arrhenius_crosscheck.m` | Q(dK) vs corrosion activation energy (Fig. 4) |
| `matlab/s3_inhibitor_efficiency.m` | inhibitor efficiency surface (Fig. 5) |
| `matlab/s4_ml_hybrid.m` | ML models, LOCO CV, blind 55 degC test (Figs. 6-8, Table 5) |
| `matlab/s5_life_integration.m` | life integration, validation, 45/65 degC predictions (Figs. 9-10) |
| `matlab/s6_probabilistic.m` | Monte Carlo design maps, B10/B50 (Fig. 11) |
| `matlab/source_data.m` | every constant taken from the two source papers |
| `data/digitized/` | consolidated dataset, one CSV per measured curve |
| `data/derived/` | pipeline outputs as shipped (regenerated by `run_all`) |
| `figures/` | result figures as shipped (regenerated by `run_all`) |

Fig. 1 of the manuscript is a montage of the published equipment
photographs and Fig. 3 is drawn directly in LaTeX; neither needs this
repository.
